# Content provenance

- User-supplied Profile.pdf: LinkedIn profile export; headline, roles, career history, interests, and publication links.
- User-supplied resume.pdf: employment dates, project details, education, skills, and reported outcomes.
- User preference: technical leadership first, hands-on engineering second.
- User explicitly requested public writing import and current-interest inference.

Professional metrics are self-reported in the supplied documents, not independently audited. Project pages retain contribution language and separate future plans from completed capabilities. No internal code, fabricated demos, or unprovided project repository links were added. LinkedIn's live page could not be retrieved; the supplied export supplied the background instead.

Publication sources are fetched from the user's public Medium and Substack feeds and Cosmic Notebook homepage/archive. Import timestamps, dates, original URLs, and refresh status are saved with the snapshot. No claim is made that a search engine has actually indexed each page.
